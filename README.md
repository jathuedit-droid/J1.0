# VisionAI — AI Photo & Video Generator

A modern responsive frontend demo for an AI photo and video generation platform.

## Run
Open `index.html` in your browser, or use VS Code + Live Server.

## Important
The included generator is a frontend demo. To generate real AI images/videos, connect the Generate button to a backend/API from an AI provider. Never expose private API keys in frontend JavaScript.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, and `script.js`.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save and open the generated Pages URL.
